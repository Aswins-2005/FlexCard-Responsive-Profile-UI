# FlexCard — Responsive Profile UI

A simple and responsive profile card UI built using **React.js, HTML, and CSS**. This project demonstrates reusable React components, props, Flexbox layouts, and responsive design.

## 🚀 Features

- 📇 Displays profile cards with name and email.
- ♻️ Reusable React components.
- 🧩 Uses props to pass data between components.
- 📱 Responsive layout for different screen sizes.
- 🎨 Clean and simple UI with CSS styling.
- ✨ Hover effects for an interactive experience.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- npm

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aswins-2005/FlexCard-Responsive-Profile-UI.git
```

### 2. Navigate to the project directory

```bash
cd FlexCard-Responsive-Profile-UI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.
